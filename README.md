# مدفع الفضاء — Space Typist 🚀

لعبة ويب عربية (RTL) لتعلم الطباعة باللمس بأسلوب «غزو الفضاء»: جمل للكتابة، ومركبات فضائية مهاجمة بعدد حروف السطر. كل حرف صحيح يطلق ليزراً على مركبة **عشوائية** ويفجرها، وكل خطأ أو تأخر عن وقت الحرف يستفز هجوماً يصيب مركبتك ويخصم قلباً.

## الأطوار
- **طور الأركيد**: موجات جمل عشوائية تتدرج صعوبة وسرعة بلا نهاية + لوحة ترتيب.
- **وضع المراحل**: 30 مرحلة بمنهجية عربية متدرجة (الصف الرئيسي ← العلوي ← السفلي ← الأرقام والرموز ← جمل كاملة) بجدول تقويم ونجوم وفتح تسلسلي.
- **تحديد المستوى**: اختبار من 3 جولات يفتح لك المرحلة المناسبة لمستواك.
- **الطور المخصص**: تعديل كامل للتوقيتات والقلوب والسرعات والمحتوى مع حفظ إعدادات مسبقة.

## المزايا
- عداد دائري لكل حرف (يمين) ولكل جملة (يسار): أخضر للوقت المتبقي وأحمر للمنقضي.
- تتبع نظر بالكاميرا (محلي 100% بلا تسجيل): إطار أخضر عند النظر للشاشة، أحمر عند النظر للوحة المفاتيح، أصفر عند تعذر التحديد.
- خيار «حروف ملتصقة» لعرض النص متصلاً كالكتابة العادية مع تشكيل عربي صحيح (ZWJ).
- أصوات مولّدة عبر Web Audio API، نتائج ومراسم ولوحة ترتيب، حفظ محلي (localStorage).

## التقنيات
React 19 + TypeScript + Vite + Tailwind CSS + shadcn/ui + Framer Motion + GSAP + Three.js (خلفية القائمة) + Zod.

## التشغيل
```bash
npm install   # يعيد توليد package-lock.json (غير مشمول في المستودع)
npm run dev
npm run build
```
